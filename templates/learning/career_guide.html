GitHub Portfolio Standards

  • Clean README.md: Architecture diagram, features list, environment variables guide, and local setup commands.
  • Live Demo URL: Pinned right at the top of the repo description (Vercel, Render, Netlify, or Railway).
  • Meaningful Commits: Avoid "commit 1" or "updates". Use conventional commits like feat: implement JWT auth or fix: resolve CORS header issue.
  • No Secrets in Git: Always add .env and node_modules/ to .gitignore.

LinkedIn Profile Checklist

  • Impact Headline: "Full-Stack Developer | Python & React | Building Scalable Cloud Apps" rather than just "Student at ABC College".
  • Featured Section: Pin your SkillRock verified certificates with live QR verification link (`https://skillrock.in/verify/`).
  • Project Posts: Share 30-second video demo walkthroughs of your milestone capstones with GitHub links.
  • Skill Assessments: Add verified skills matching your actual project stack.
